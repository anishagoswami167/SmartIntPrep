# Stack Interview Cheat Sheet

| If Question Says   | Pattern           |
| ------------------ | ----------------- |
| Matching brackets  | Valid Parentheses |
| Undo operation     | Stack             |
| Remove recent item | Stack             |
| Current minimum    | Min Stack         |
| Current maximum    | Max Stack         |
| Next greater       | Monotonic Stack   |
| Next smaller       | Monotonic Stack   |
| Previous greater   | Monotonic Stack   |
| Previous smaller   | Monotonic Stack   |
| Warmer day         | Monotonic Stack   |
| Stock span         | Monotonic Stack   |
| Largest rectangle  | Monotonic Stack   |

---

### My recommendation

Practice in this order:

```text
1. Valid Parentheses 
2. Min Stack 
3. Next Greater Element 
4. Next Smaller Element
5. Previous Greater Element
6. Previous Smaller Element
7. Stock Span
8. Daily Temperatures Revision
9. Largest Rectangle in Histogram
```

After these 9 questions, you'll have covered almost all important Stack patterns used in interviews.
