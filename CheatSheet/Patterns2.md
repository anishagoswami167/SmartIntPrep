Exactly. That's the mindset that helps most in interviews.

The goal is **not**:

```text
Solve 500 LeetCode questions
```

The goal is:

```text
See a new problem
↓
Recognize the pattern in 30 seconds
↓
Know the data structure
↓
Write the solution
```

Interviewers are testing pattern recognition more than memorized solutions.

# The DSA Pattern Roadmap

There are roughly **12-15 major patterns** that cover a huge percentage of interview questions.

## Pattern 1: HashMap / Frequency Count

### Clues

```text
Count
Frequency
Occurrence
Duplicate
Anagram
Lookup
```

### Questions

Easy

1. Two Sum
2. Contains Duplicate
3. Valid Anagram
4. First Non-Repeating Character
5. Majority Element

Medium
6. Group Anagrams
7. Top K Frequent Elements
8. Longest Consecutive Sequence

# The Cheat Sheet You Should Memorize

```text
Count/Frequency           → HashMap
Unique Elements           → Set
Sorted Array              → Two Pointers / Binary Search
Pair Problems             → Two Pointers
Subarray                  → Sliding Window
Substring                 → Sliding Window
Matching Brackets         → Stack
Nearest Greater           → Stack
Level Order               → Queue/BFS
Shortest Path             → BFS
Tree Depth                → DFS
Connected Components      → DFS/BFS
Top K                     → Heap
All Combinations          → Backtracking
Optimization              → Dynamic Programming
```
